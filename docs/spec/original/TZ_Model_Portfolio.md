# ТЗ: модуль «Модельный портфель» (дополнение к «Утреннему радару»)

## 1. Суть
Гипотетический (модельный) инвестпортфель на **1 000 000 ₽**, который агент ведёт на основе накопленной аналитики из ежедневных радаров. Это учебно-аналитический инструмент, не реальные торговые операции и не индивидуальная инвестрекомендация — это отражается в каждом отчёте.

## 2. Периодичность
- **Плановый пересмотр**: раз в неделю (например, утро понедельника, после недельного радара).
- **Внеплановый пересмотр**: в любой день, если этого требует ситуация (резкое движение рынка, санкционный шок, обвал/ралли — по аналогии с капитуляцией IMOEX 14.08). Триггер — либо запрос пользователя вручную, либо сам агент помечает в дневном радаре флаг «требуется внеплановый пересмотр портфеля», и следующий запуск включает ребалансировку.

## 3. Допустимая вселенная активов (неквалифицированный инвестор, ИИС)
Неквалифицированному инвестору без тестирования доступны: <cite index="13-1">акции из котировальных списков (котировальная часть списка), ОФЗ и другие базовые, не самые рискованные инструменты</cite>. Недоступны без теста: маржинальная торговля, ПФИ (фьючерсы/опционы), структурные и субординированные облигации, иностранные акции вне одобренного перечня.

Соответственно, в модельный портфель допускаются только:
- **Акции РФ** — эмитенты из индекса МосБиржи / котировальных списков первого-второго уровня (голубые фишки + ликвидные истории роста)
- **Облигации** — ОФЗ и корпоративные облигации без структурных выплат (обычные купонные)
- **Золото** — через биржевые инструменты, доступные неквалам (например, торгуемый на бирже золотой инструмент/БПИФ на золото, не физическое серебро/платина и не структурные ноты на золото)
- **Кэш / денежный рынок** — для доли, не находящейся в риске (фонды денежного рынка, короткие ОФЗ, депозит)

**Важно:** правила для неквалов периодически меняются (ЦБ РФ регулярно расширяет/сужает список доступных облигаций и т.п.). Раз в квартал агент должен через веб-поиск сверять актуальный список ограничений, а не полагаться на статичное правило.

## 4. Формат распределения (что агент выдаёт)
Таблица вида:

| Класс актива | Тикер/инструмент | Доля,% | Сумма, ₽ |
|---|---|---|---|
| Акции | SBER | 15% | 150 000 |
| Акции | LKOH | 10% | 100 000 |
| Облигации | ОФЗ 26238 | 20% | 200 000 |
| Облигации | Корп. облигация Х | 10% | 100 000 |
| Золото | БПИФ на золото | 15% | 150 000 |
| Кэш/денежный рынок | — | 30% | 300 000 |

Плюс краткое обоснование (3-5 предложений): почему такое распределение, какие риски радара на это повлияли, что изменилось с прошлой версии.

## 5. Логика принятия решений
Агент перед каждым пересмотром:
1. Поднимает историю ежедневных радаров (см. `radar_history.jsonl`) за период с прошлого пересмотра портфеля
2. Выделяет: тренд рубля, ставки, ОФЗ, IMOEX, ключевые риски и их динамику
3. Соотносит с текущим составом портфеля — что оправдалось, что нет
4. Предлагает новое распределение с объяснением каждого значимого изменения (не просто "стало по-другому", а "потому что...")
5. Не делает резких стилистических метаний — если рынок не дал нового сильного сигнала, распределение может остаться почти без изменений

## 6. История портфеля (обязательно)
Хранить компактно, при каждом пересмотре добавлять запись (не переписывать историю):
- Дата
- Общая стоимость портфеля на этот момент (с учётом переоценки активов по факту, не только новых решений)
- Распределение (список: класс/тикер/доля/сумма)
- Тип пересмотра (плановый/внеплановый) и краткая причина
- Изменение стоимости с момента запуска (₽ и %)

Формат: `portfolio_history.jsonl`, одна строка JSON на запись, пример:
```json
{"date":"2026-08-24","total_value":1010500,"change_pct_since_start":1.05,"trigger":"weekly","reason":"ослабление рубля и рост доходности ОФЗ 10л выше 15.5%","allocations":[{"class":"акции","ticker":"SBER","pct":15,"value":151575},{"class":"облигации","ticker":"ОФЗ 26238","pct":20,"value":202100},{"class":"золото","ticker":"БПИФ TGLD","pct":15,"value":151575},{"class":"кэш","ticker":"—","pct":50,"value":505250}]}
```

## 7. Формат отчёта
Отдельный PDF в той же дизайн-системе (`RU_Model_Portfolio_YYYY-MM-DD.pdf`):
- Титул: дата, тип пересмотра, текущая стоимость портфеля и изменение с начала
- Таблица распределения (карточки/таблица, как в watchlist радара)
- Диаграмма распределения по классам активов
- Динамика стоимости портфеля во времени (график по истории)
- Обоснование решений (что изменилось и почему)
- Дисклеймер: модельный/гипотетический портфель, не является индивидуальной инвестиционной рекомендацией, не реальные сделки

## 8. Открытый вопрос
Уточнить у пользователя стартовую дату отсчёта (когда считать день 0 портфеля с суммой 1 000 000 ₽) и стартовое распределение (агент предлагает первое распределение сам на основе последнего радара, либо пользователь задаёт вручную).
