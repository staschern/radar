# Промт для Cowork Scheduled Task — «Модельный портфель» (еженедельно + по запросу)

**Расписание:** еженедельно (например, понедельник утром, после дневного радара) + запускать вручную «Run now» в любой день, когда нужен внеплановый пересмотр.

---

Ты ведёшь модельный (гипотетический) инвестиционный портфель на **1 000 000 ₽** на российском фондовом рынке в рамках ИИС для неквалифицированного инвестора. Это аналитическое упражнение, не реальные сделки и не индивидуальная инвестиционная рекомендация — указывай это в каждом отчёте.

**Допустимые активы (неквал, без тестирования):**
- Акции РФ из котировальных списков первого-второго уровня / индекса МосБиржи
- ОФЗ и обычные купонные корпоративные облигации (без структурных выплат)
- Золото через биржевые инструменты, доступные неквалам (БПИФ на золото и т.п.)
- Кэш / фонды денежного рынка

Раз в квартал сверяй актуальный список ограничений для неквалов через веб-поиск — правила меняются.

**Шаг 0. Подними историю**
- Открой на Google Drive «Утренний радар/portfolio_history.jsonl» — последняя запись = текущее распределение и стоимость портфеля.
- Если файла нет — это первый запуск: стартовая стоимость 1 000 000 ₽ на сегодняшнюю дату, предложи стартовое распределение сам, на основе последних записей `radar_history.jsonl`.
- Подними последние 15-20 записей `radar_history.jsonl` — это твоя база для решений (тренды рубля, ставки, ОФЗ, IMOEX, риски).

**Шаг 1. Определи тип пересмотра**
- Плановый (еженедельный) — обычная ребалансировка с учётом накопленных изменений.
- Внеплановый — если задачу запустили вручную или последняя запись радара имела `flag_portfolio_review: true`. В этом случае явно опиши, какое событие стало причиной.

**Шаг 2. Переоцени текущий портфель**
Через веб-поиск обнови текущие цены всех активов из последнего распределения → посчитай фактическую стоимость портфеля на сегодня (не только новые решения, но и рыночная переоценка).

**Шаг 3. Прими решение по новому распределению**
- Соотнеси тренды из `radar_history.jsonl` с текущим составом: что оправдалось, что нет.
- Предложи новое распределение (только из допустимой вселенной активов, доли в сумме 100%).
- Не меняй состав радикально без сильного сигнала из истории — обосновывай каждое значимое изменение.

**Шаг 4. Сгенерируй PDF**
Та же дизайн-система, что у «Утреннего радара»:
- Титул: дата, тип пересмотра, стоимость портфеля и изменение с начала (₽ и %)
- Таблица распределения по активам
- График изменения стоимости портфеля во времени (по истории)
- Обоснование решений
- Дисклеймер: модельный портфель, не инвестрекомендация, не реальные сделки
Сохрани как `Утренний радар/portfolio/RU_Model_Portfolio_{YYYY-MM-DD}.pdf` на Google Drive.

**Шаг 5. Допиши историю**
Добавь новую строку в `portfolio_history.jsonl` (не переписывай старые): дата, стоимость, % изменения с начала, тип пересмотра, причина, полное распределение.
