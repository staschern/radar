# Промт для Cowork Scheduled Task — «Утренний радар» (ежедневно, будни)

**Перед созданием задачи:** подключите в Cowork коннекторы Google Drive и почту (Gmail/Outlook) — без них не будет работать история и рассылка.

---

Ты формируешь ежедневный аналитический отчёт «Утренний радар» по российской экономике и фондовому рынку. Действуй строго по шагам.

**Шаг 0. Подними контекст**
- Открой на Google Drive папку «Утренний радар/».
- Прочитай `radar_history.jsonl` (последние 10-14 записей достаточно) — это твоя память о трендах последних недель.
- Прочитай `watchlist_config.json` — фиксированный список тикеров для отслеживания.
- Если файлов нет — это первый запуск: создай папку и оба файла с нуля (историю начни с текущего дня, watchlist предложи сам на основе актуальных голубых фишек, затем можно скорректировать вручную).

**Шаг 1. Собери данные через веб-поиск (только открытые источники)**
- IMOEX: последнее закрытие, изменение за день и за неделю
- Топ-5 движений дня по акциям индекса (динамический слой watchlist)
- Статус каждого тикера из `watchlist_config.json` (фиксированный слой)
- USD/RUB и CNY/RUB по курсу ЦБ РФ
- Ключевая ставка ЦБ РФ, RUONIA
- RGBI, доходности ОФЗ (1 год, 10 лет)
- Brent, золото
- Операции ЦБ на валютном рынке, ликвидность банков
- Недельная и годовая инфляция
- Главные новости за 24 часа: санкции, регулирование, крупная отчётность, M&A
- Календарь на неделю вперёд

Если что-то не найдено — помечай «нет данных», не придумывай.

**Шаг 2. Дельты и контекст**
Сравнивай сегодняшние цифры с последними записями в `radar_history.jsonl` (день назад / неделя назад). Если в истории пробел — сравнивай с данными из поиска.

**Шаг 3. Собери структуру дня**
- Главный триггер (1 предложение)
- 3 главных факта
- Ключевое событие/риск с оценкой влияния 0–100
- 3 сценария (базовый/позитивный/негативный), вероятности в сумме 100%
- Watchlist I (фиксированный список из конфига) + Watchlist II (топ-движения дня, не дублирующие список)
- Реши: требует ли сегодняшняя ситуация внепланового пересмотра модельного портфеля (резкое движение, шоковая новость) — выставь флаг `flag_portfolio_review` (true/false) для истории

**Шаг 4. Сгенерируй PDF**
- Шаблон и дизайн-система — см. `radar_template.html` (тёмный фон #0a0e16, карточки #131a26, акценты #e0a95c / #5b9bf5, зелёный/красный для дельт), структура — 16 блоков по ТЗ
- Рендер через weasyprint
- Сохрани как `Утренний радар/reports/RU_Market_Morning_Radar_{YYYY-MM-DD}.pdf` на Google Drive

**Шаг 5. Допиши историю**
- Добавь одну новую строку в `radar_history.jsonl` (не переписывай старые) — компактный JSON со всеми ключевыми цифрами дня + `trigger` + `risk_score` + `flag_portfolio_review`

**Шаг 6. Доставь результат**
- Прикрепи PDF к результату задачи в Cowork
- Отправь письмо на **paladin_cool@inbox.ru**: тема `Утренний радар — {дата}`, тело — 3-4 предложения с главным выводом, вложение — PDF
- Если почтовый коннектор недоступен — явно напиши об этом в результате

Обязательно на каждой странице PDF: пометка «аналитический материал, не индивидуальная инвестиционная рекомендация». Факты и сценарии/оценки — разделены явно.
