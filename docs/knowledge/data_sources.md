# Источники данных

Реестр источников с приоритетами и известными подвохами. Дополняется по мере
столкновения с реальными проблемами сбора.

## Приоритет источников
1. **Первичный источник** (ЦБ РФ, МосБиржа, Росстат, сайт эмитента) — всегда предпочтительнее.
2. **Агрегатор** (investing.com, smart-lab, finam, profinance) — когда первичный
   недоступен; в отчёте указывается, что данные с агрегатора.
3. **СМИ** — только для новостей и контекста, не для чисел.

## Правила
- Каждое число в отчёте должно быть отслеживаемо до источника. Если источник —
  агрегатор, это указывается.
- При расхождении источников на существенную величину — брать первичный и
  упомянуть расхождение.
- Время публикации ЦБ (~07:15–07:30 мск) определяет самое раннее осмысленное время
  запуска задачи. **Требует фактической проверки перед настройкой расписания**
  (открытый вопрос №1 в ТЗ Радар §12).
