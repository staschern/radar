# Бэклог идей и улучшений

Идеи, которые обсуждались или пришли в голову агенту, но не входят в текущее ТЗ.
Ничего отсюда не реализуется без подтверждения заказчика. Реализованное
переносится в раздел «Сделано» с ссылкой на коммит/ADR.

Приоритет: 🔴 высокий · 🟡 средний · ⚪ когда-нибудь

## Отчётность и аналитика
- 🔴 **Блок «что подтвердилось»** в дневной сводке — калибровка качества прогнозов.
  *(включено в v1.1, шаблон готов)*
- 🟡 **Месячная свёртка** `data/monthly/YYYY-MM.md` из дневных сводок — обзор
  «что было за месяц» без чтения 20 файлов. Решать после первого месяца данных.
- 🟡 **Скоринг калибровки**: доля сбывшихся базовых сценариев, систематические
  смещения вероятностей. Требует ~20 наблюдений.
- 🔴 **Сравнение с бенчмарком** в отчёте портфеля: модельный портфель vs MCFTR
  (индекс полной доходности) vs депозит по ключевой ставке. Данные теперь
  доступны через ISS, реализуемо сразу. Приоритет поднят: без бенчмарка
  невозможно понять, добавляет ли активное ведение портфеля ценность.
- 🟡 **Симуляция Монте-Карло** для проекции вместо гладкой доходности: при
  стандартном отклонении 39,2% годовых средняя траектория мало что говорит о
  распределении исходов. Дало бы вероятность достичь цели, а не одну цифру.
- ⚪ **Индекс новостного фона** (0–100) как отдельная метрика в истории — чтобы
  ретроспективно видеть периоды повышенного шума.

## Данные и автоматизация
- 🟡 **Скрипт валидации** `data/*.jsonl` против схем из `data_schemas.md`
  (проверка обязательных полей, суммы долей = 100%, хронологии дат). Дёшево и
  ловит ошибки до коммита.
- 🟡 **Сводка трендов за N дней** — небольшой скрипт, считающий из `radar_history.jsonl`
  направления по IMOEX/USD/ставке/ОФЗ, чтобы агент не пересчитывал вручную.
- ⚪ **Автоматическая свёртка истории** по достижении ~400 строк.
- ⚪ **Проверка ссылок и целостности отчётов** перед коммитом.

## Портфель
- 🟡 **Учёт комиссий** в переоценке (0.05% на сделку) — открытый вопрос №4 ТЗ Портфель.
- 🟡 **Стресс-тест распределения**: что будет с портфелем при −20% по IMOEX,
  +10% по USD/RUB, +200 б.п. по ОФЗ. Считается арифметически, добавляет
  предметности обоснованию.
- ⚪ **Дивидендный календарь** для позиций портфеля в отчёте.
- ⚪ **Учёт ЛДВ** (3+ года) при обосновании продаж, если счёт обычный брокерский.

## Watchlist
- 🟡 **Предложения кандидатов**: агент по итогам недели предлагает 2–3 тикера
  для фиксированного списка с обоснованием. Пользователь решает. Не нарушает
  правило «агент не наполняет список сам».
- ⚪ **Фильтр ликвидности** для динамического слоя: отсекать движения на объёме
  ниже порога, чтобы в топ-5 не попадал неликвид.
