# `templates/` — дизайн-система отчётов

`radar_template.html` — эталонная разметка и единый источник правды по визуальному
стандарту (ТЗ Радар §6). Используется обоими отчётами: радаром и модельным портфелем.

## Палитра

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#0a0e16` | Фон страницы |
| `--card` | `#131a26` | Карточка/секция |
| `--card-2` | `#0f1520` | Вложенная карточка |
| `--line` | `#232d3d` | Рамки, разделители |
| `--gold` | `#e0a95c` | Заголовки блоков, ключевая ставка, акценты |
| `--blue` | `#5b9bf5` | Валютные метрики, пометка «факт» |
| `--up` / `--down` | `#5bd88a` / `#e08a8a` | Рост / падение |
| `--muted` / `--dim` | `#8a97ab` / `#5d6879` | Подписи, служебный текст |

Скругления 12–14px, заголовки 30–44px, гротеск.

## Правила
1. **Самодостаточность.** Инлайн CSS и SVG, никаких CDN, внешних картинок и скриптов —
   иначе отчёт ломается офлайн и в почтовом клиенте ([ADR-0002](../docs/decisions/ADR-0002-html-instead-of-pdf.md)).
2. **Факт ≠ оценка.** Классы `.tag.fact` и `.tag.est`, служебный `.est-note`.
   Всё, что получено рассуждением, помечается явно — требование ТЗ §8.
3. **Дисклеймер** в футере каждой секции и развёрнутый блок внизу страницы.
4. **Нет данных** → класс `.nodata` и текст «нет данных». Не пропускать, не выдумывать.
5. **Пустое состояние** (`.empty`) — для пустого фиксированного watchlist.
6. **Адаптивность и печать** — таблицы в `.tablewrap` с горизонтальной прокруткой,
   `break-inside: avoid` у карточек для «Печать → PDF».

## Плейсхолдеры
Вид `{{ ключ }}`. Блоки с комментарием `<!-- REPEAT -->` повторяются по числу
элементов. Шаблон покрывает блоки 1–4, 9, 11, 12, 15, 16; блоки 5–8, 10, 13, 14
собираются из тех же примитивов (`section` + `h2`/`h3` + `.cards`/`.tablewrap`).
