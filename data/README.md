# `data/` — машинная история проекта

Все файлы здесь **append-only**: строки только дописываются, прошлые записи не
редактируются. Исправление ошибки — новая строка с полем `corrects` и коммит,
объясняющий правку. Полные схемы — [`docs/knowledge/data_schemas.md`](../docs/knowledge/data_schemas.md).

| Файл | Что | Кто пишет |
|---|---|---|
| `watchlist_config.json` | Фиксированный список тикеров. **Стартует пустым.** | Только по указанию пользователя |
| `watchlist_inflation_hedge.json` | Устойчивые к инфляции акции (с v1.6). **Стартует пустым.** | Агент может сам предлагать кандидатов (ТЗ Радар §9.3) |
| `radar_history.jsonl` | 1 строка на день: числа, дельты, триггер, risk_score | Задача «Утренний радар», Шаг 5 |
| `global_macro_history.jsonl` | Госдолг США/доллар/обесценивание валют (с v1.6). Лог событий, не ежедневный | Задача «Утренний радар», Шаг 1а/5, только при новом релизе |
| `portfolio_history.jsonl` | 1 строка на пересмотр портфеля: стоимость и распределение | Задача «Модельный портфель», Шаг 5 |
| `daily/YYYY-MM-DD.md` | Человекочитаемая сводка дня (~40 строк) | Задача «Утренний радар», Шаг 5 |
