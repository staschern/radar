# `data/daily/` — сжатые сводки дня

Один файл на торговый день: `YYYY-MM-DD.md`, до ~40 строк, жёсткий шаблон —
[`docs/knowledge/daily_summary_template.md`](../../docs/knowledge/daily_summary_template.md).

Назначение: восстановить контекст дня за 20 секунд, не открывая полный
16-блочный отчёт. Дополняет `radar_history.jsonl` тем, что не влезает в JSON:
причины, ожидания и блок «что подтвердилось из прошлого раза».

Пусто — ни одного запуска ещё не было.
