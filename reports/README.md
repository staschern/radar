|---|---|

Формат — самодостаточный HTML (один файл, инлайн CSS и SVG, без внешних запросов),
см. [ADR-0002](../docs/decisions/ADR-0002-html-instead-of-pdf.md). PDF при
необходимости получается печатью из браузера.
