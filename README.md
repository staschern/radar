# Утренний радар + Модельный портфель

Два связанных ИИ-агента для российского рынка:

- **«Утренний радар»** — ежедневный (будни) аналитический дайджест из 16 блоков в
  формате самодостаточного HTML, готовый к открытию рынка.
- **«Модельный портфель»** — гипотетический портфель на 1 000 000 ₽, который
  ведётся еженедельно на основе накопленной аналитики радаров.

Запуск — через Claude Cowork Scheduled Tasks. Вся история, знания и наработки
хранятся в этом репозитории и обновляются при каждом взаимодействии.

> ⚠️ **Материалы проекта носят информационно-аналитический характер и не являются
> индивидуальной инвестиционной рекомендацией.** Портфель модельный
> (гипотетический), реальные сделки не совершаются.

## Ключевые принципы

1. **Факт ≠ оценка.** Всё, что получено рассуждением (уровни, risk_score,
   вероятности), помечается явно. Отсутствующие данные — «нет данных», никогда не
   выдуманное число.
2. **История только дописывается.** Прошлые записи не переписываются; исправление —
   новая строка с полем `corrects`.
3. **Каждый запуск завершается коммитом.** Окружение задачи эфемерно: не
   закоммичено — потеряно.
4. **Два слоя истории.** JSONL для расчётов, markdown-сводка для контекста и
   калибровки прогнозов ([ADR-0003](docs/decisions/ADR-0003-two-layer-history.md)).
5. **Watchlist наполняет только пользователь.** Агент может предлагать кандидатов,
   но не добавляет тикеры сам.
6. **Портфель не стартует без инвестпрофиля.**
